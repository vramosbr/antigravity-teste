# Antigravity Sem Código — Guia Prático de Criação com IA e Modelos Google

Aplicação web interativa desenvolvida para capacitar criadores não técnicos (analistas, gestores, empreendedores, educadores e consultores) a utilizarem o **Google Antigravity** e os modelos **Google Gemini** na criação de aplicativos, soluções com Inteligência Artificial e automações do dia a dia.

## O que está incluído

- **5 Módulos Didáticos**:
  1. Entendendo o Antigravity na Prática (Chatbot vs. Ambiente Agêntico e Mapa da Interface)
  2. Dominando os Modelos Google (Gemini Pro vs. Gemini Flash, Estratégia "Troca Inteligente" e uso da API do Gemini dentro dos apps)
  3. O Método "Da Ideia ao Aplicativo" em 4 Passos
  4. Trilhas Práticas por Tipo de Demanda (Apps Web Internos, Soluções com IA Integrada e Automações/Produtividade)
  5. Kit de Sobrevivência e Resolução de Problemas (Erros, Ajustes Visuais com Prints e Segurança de API Keys)
- **5 Ferramentas Interativas**:
  - Seletor Interativo de Modelo Google (Quiz de 3 perguntas)
  - Biblioteca de Prompts Copiáveis com campos `[PREENCHA AQUI]` e preenchimento opcional inline
  - Glossário Tradutor ("Tech → Português Claro") acessível na navegação e em modal rápido
  - Simulador Interativo de Fluxo Agêntico em 4 etapas
  - Checklist de Progresso do Criador salvo automaticamente no `localStorage`
- **Experiência**: Busca global instantânea, menu lateral responsivo (desktop + gaveta mobile) e alternância entre Tema Claro e Tema Escuro.

## Como executar localmente

```bash
npm install
npm run dev
```
